# 🚀 042 Web Birthday Invitation

A retro 90s birthday invitation page, built with plain HTML and CSS. Day 42 of
the Udemy "100 Days of Code" web development course.

## 🧭 Overview

The page shows:

- the date of the party as headings
- a picture of the birthday cake
- a list of what the guests bring
- a link to the location on Google Maps

| File | Purpose |
| --- | --- |
| `src/index.html` | The page: headings, image, list and anchor tag |
| `src/style.css` | The retro 90s look |
| `tests/manual-checklist.md` | The checks of the page, run by hand in a browser |

## 📋 Requirements

A web browser. There is no build step, no package to install and no server.

## 🛠️ Setup

Clone the repository:

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/042-web-birthday-invitation.git
cd 042-web-birthday-invitation
```

## ▶️ Run

No build step. Open `src/index.html` in a browser.

## 🧪 Tests

The tests are a manual checklist, because the whole product is one static page. Open `src/index.html`, then go through the items of [`tests/manual-checklist.md`](./tests/manual-checklist.md) (one `h1`, one `h2`, one picture with `alt` text, the list, the map link, the stylesheet, a narrow window and the page title).
