# 042-web-birthday-invitation

A retro 90s birthday invitation page, built with plain HTML and CSS. Day 42 of
the Udemy "100 Days of Code" web development course.

![The birthday invitation page](docs/wiki/images/birthday-invitation.png)

## What it shows

- the date of the party as headings
- a picture of the birthday cake
- a list of what the guests bring
- a link to the location on Google Maps

## Run it

No build step. Open `src/index.html` in a browser.

## Files

| File | Purpose |
| --- | --- |
| `src/index.html` | The page: headings, image, list and anchor tag |
| `src/style.css` | The retro 90s look |
