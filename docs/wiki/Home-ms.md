# Jemputan Hari Lahir

🌐 [English](Home) · [Dansk](Home-da) · **Bahasa Melayu**

Halaman jemputan hari lahir bergaya retro 90-an, dibina dengan HTML dan CSS
biasa. Hari ke-42 kursus pembangunan web "100 Days of Code" di Udemy.

![Halaman jemputan hari lahir](images/birthday-invitation.png)

## Apa yang digunakan halaman ini

| Elemen | Digunakan untuk |
| --- | --- |
| `<h1>`, `<h2>`, `<h3>` | Tajuk, tarikh dan tajuk bahagian |
| `<img>` | Kek hari lahir, dengan teks `alt` |
| `<ul>` dan `<li>` | Apa yang tetamu bawa |
| `<a>` | Pautan Google Maps ke majlis |

## Fail

| Fail | Tujuan |
| --- | --- |
| `src/index.html` | Halaman itu sendiri |
| `src/style.css` | Warna, fon, bingkai dan reka letak, dipaut dari halaman |

## Jalankan

Tiada langkah binaan. Buka `src/index.html` dalam pelayar.

## Penggayaan

Gaya berada dalam `src/style.css`, bukan dalam HTML. Empat sifat tersuai di
bahagian atas (`--bg`, `--ink`, `--accent`, `--link`) menetapkan warna, jadi
rupa baharu hanya perlu menukar empat nilai.
